# 구술채록 용역 입찰·발주 목록 (나라장터)

조달청 발주계획·입찰공고를 그대로 옮겨 싣는 미러(씬디스 `seenthis.kr`)에서 낱말 다섯
(`구술`·`채록`·`증언`·`생애사`·`기록화`)으로 두 게시판을 쪽 넘김까지 훑어 315건을 받고, 제목에 구술이
걸리는 **103건**을 남겼다. 서·논·구술형 평가 플랫폼, 체육지도자 실기구술, 남극이빨고기 생애사처럼
낱말만 같은 것은 걷어 냈다.

**이 목록에는 아직 낙찰자가 없다 — 다만 볼 수는 있다(2026-08-28 정정).** 미러가 싣는 것은 공고문뿐이지만,
나라장터 본 화면의 **「입찰개찰/낙찰 › 개찰결과분류조회」**에 공고번호를 넣으면 투찰 업체·투찰금액·순위가
그대로 나온다. 앞서 "자동화 차단이라 개찰 결과를 못 본다"고 적었던 것은 틀렸다 — 막힌 것은 내 자동화지
자료가 아니다(`g2b.go.kr` 첫 화면만 빈 페이지가 오고, `/link/PNPE027_01/single/?bidPbancNo=…` 상세는 열린다).

**그래도 64건을 손으로 다 열기는 어렵다.** 화면이 WebSquare라 공고 하나마다 조회 → 행 선택 → 판독을
거쳐야 하고, 개찰일자 범위가 좁아 연도별로 나눠 걸어야 한다. **깨끗한 길은 API다** —
**「조달청_나라장터 낙찰정보서비스」(공공데이터포털 15129397)**, 엔드포인트 `/1230000/as/ScsbidInfoService`.
없는 서비스가 아니라 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 오므로 **활용신청 승인만 받으면 열린다.**
표의 마지막 칸이 담당자에서 끊기는 것은 그때까지다.
